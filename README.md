# DARROX ICT Request Queue
Vercel-ready Next.js application based on the DAR Regional Office X ICT Services Repair Request Form.

## Vercel
If your GitHub repository contains these files at the repository root, import it directly into Vercel. If the project is inside a subfolder, set **Root Directory** to that folder.

No Supabase environment variables are required for the demo: requests are stored in browser localStorage. For shared multi-user monitoring, configure Supabase using the included SQL schema and environment variables.
